# North Star Bakery Touchstone 4

This project continues the North Star Bakery website from Touchstones 2 and 3. Touchstone 4 adds JavaScript interactivity, form validation, and browser storage while preserving the existing responsive design.

## Pages

- `index.html`
- `products.html`
- `about.html`
- `contact.html`

## Touchstone 4 features

- Interactive pre-order list builder on `products.html`
- Dynamic list updates with add and remove actions
- JavaScript validation with field-specific feedback on `contact.html`
- `localStorage` for the saved pre-order list and contact form draft
- Organized functions, arrays, and objects in `app.js`
- Five automated logic tests in `tests/app.test.js`

## Run the tests

```text
node --test tests/app.test.js
```

Open `index.html` to view the site locally.
